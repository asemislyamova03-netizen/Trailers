# AGENTS.md - trailers

## Назначение проекта

Этот проект относится к направлению trailers / прицепы / товарное направление.

Это отдельный проект. Его нельзя смешивать с clinic app и flexity admin.

## Контекст

Проект связан с товарным направлением и клиентскими задачами по прицепам.

## Правила работы

- Не смешивать задачи trailers с clinic app.
- Не переносить бизнес-логику суперструктуры из flexity admin без явного запроса.
- Перед изменениями определить модуль и риск.
- После работы фиксировать состояние проекта.
- Всегда указывать следующий конкретный шаг.

## Что важно отслеживать

- текущие задачи по проекту;
- клиентские запросы;
- что уже реализовано;
- что требует доработки;
- что связано с продажами или подписочной моделью;
- следующий шаг.
