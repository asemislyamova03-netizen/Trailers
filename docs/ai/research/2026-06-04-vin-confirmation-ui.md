# Research Brief: VIN confirmation UI

Date: 2026-06-04
Status: approved

## Goal

Понять, почему после присвоения VIN статус заказа остаётся `Ждёт подтверждения VIN`, а на экране логиста нет понятного действия.

## Original request

Производство выпустило прицеп, VIN привязали, статус показывает `ждёт подтверждение VIN`. У логиста видно `ждёт подтверждения нанесения`, но при открытии нет кнопки подтверждения.

## What I inspected

| File / Source | Finding |
|---|---|
| `views.py` | `vin_registry_confirm` доступен только ролям `manager`, `director`. |
| `views.py` | Для роли `logistics` `/logistics/workspace` редиректит в `/logistics/vin-registry`. |
| `templates/vin_registry_list.html` | Для `assigned` есть только кнопка `Открыть`, без подсказки, что подтверждает менеджер/директор. |
| `templates/vin_registry_detail.html` | Блок `Подтвердить нанесение` скрыт от логиста; если других действий нет, экран выглядит пустым. |
| `templates/manager_workspace.html` | У менеджера уже есть POST-кнопка `Подтвердить VIN`. |

## Current codebase facts

- `assigned` означает VIN привязан к Trailer, но нанесение ещё не подтверждено.
- Подтверждение меняет статус VIN на `confirmed` и синхронизирует строку заказа в `vin_confirmed`.
- Текущее право подтверждения: менеджер/директор.

## Constraints

- Не расширять права логиста без отдельного решения.
- Не менять VIN-модель, статусы и миграции.
- Не менять бизнес-событие подтверждения, только UI-пояснение/доступное действие.

## Risks

| Risk | Severity | Mitigation |
|---|---|---|
| Логист считает, что должен подтвердить VIN, но не может | medium | Показать явное сообщение, кто подтверждает. |
| Менеджер/директор не видят быстрый путь к подтверждению | medium | Добавить кнопку подтверждения в реестр/карточку, где роль уже имеет право. |
| Случайно расширить permissions | high | Не менять `@role_required('manager', 'director')`. |

## Recommendation

Оставить права как есть, но улучшить UI:

- В реестре VIN для `assigned`: менеджеру/директору показать кнопку `Подтвердить`; логисту показать бейдж/подсказку `Подтверждает менеджер`.
- В карточке VIN для логиста показать информационный блок, что VIN назначен и ждёт подтверждения менеджера/директора.
