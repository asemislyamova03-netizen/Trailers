## Что нельзя забыть

- Не смешивать trailers с clinic app и flexity admin.
- Цены по конфигурации могут быть не заполнены и не должны блокировать заказ.
- Источник выбора параметров конфигуратора - матрица допустимости, а не справочник номенклатуры и не ценовые матрицы.
- Разные прицепы в одном заказе должны жить как разные строки заказа, а не как количество одной строки.
- Выдача документов и отгрузка должны проверяться по строкам заказа, иначе один VIN может ошибочно закрыть весь заказ.
- Удаление заказа должно оставаться безопасным: нельзя удалять заказ, если уже есть резервы, VIN, договор, оплаты, производство, перемещения, документы или отгрузка.
- Токен Kaspi нельзя коммитить в репозиторий; хранить только в переменных окружения или закрытых настройках сервера.
- Текущий сервер не получает ответ от `kaspi.kz`; проверку Kaspi продолжать на хостинге организации или другом IP.
- Kaspi и будущий WhatsApp должны попадать в общий контур `Lead`/`LeadMessage`, чтобы менеджер видел их в диалогах, а не в отдельном изолированном разделе.
- Отчеты для менеджера должны оставаться ограничены его складом/назначенными заказами.
- Для исторических отчетов источник выручки должен быть договор/продажа с датой и суммой, а не просто VIN в остатках.
- Исправления конкретных импортированных договоров по артикулам выполняются вручную пользователем, если это бизнес-корректировка данных.
- Для исправления директорских отчетов по историческим договорам использовать отчетные поля договора `warehouse_id` и `assigned_user_id`, не менять фактический склад прицепа без отдельного запроса.
- Исторические заказы можно создавать задним числом; связку с уже существующим договором делать отдельной проверяемой командой, чтобы не сломать договор/VIN.
- Комплекты запасных частей нельзя бездумно проводить как прицепы: нужен отдельный контур для номенклатуры без VIN.
- У производственника в левом меню не должно быть нескольких активных пунктов на одном экране.
- Выручка в новой модели должна считаться по проведённым реализациям, а договор/документы АвтоЦОНа остаются юридическим оформлением прицепа.
- Старую кнопку `Комплектация` нельзя оставлять как простую смену `item_id`; следующий шаг - перевод на складскую операцию с BOM и остатками.
