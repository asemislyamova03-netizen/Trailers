# NEXT_ACTIONS.md

## Следующие действия

1. Подтянуть изменения на сервер и перезапустить приложение.
2. На сервере запустить проверку синтаксиса через рабочий venv: `venv/bin/python -m py_compile views.py`.
3. Проверить в заказе `ORD-000043`: кнопка “Добавить другую конфигурацию через подбор” должна открывать подбор в режиме добавления позиции к заказу.
4. Проверить добавление второй другой конфигурации в производство: должна появиться отдельная строка заказа и `SupplyNeed` с `order_line_id`.
5. Проверить добавление другой конфигурации из наличия: выбранный VIN должен резервироваться отдельной строкой заказа.
6. Проверить удаление пустого тестового заказа админом; заказ с резервом, VIN, оплатой, договором, производством или перемещением должен блокироваться.
7. Проверить создание договора по заказу с разными строками: в `sales_contract_line` должны появиться строки, печатная спецификация должна вывести несколько позиций.
8. Добавить редактирование/удаление строк заказа до выдачи документов.
9. Добавить привязку VIN/выпуска производства к конкретной строке заказа из UI.
10. Спроектировать выбор шаблонов договоров по группе/ОТТС/модификации.
11. Спроектировать списание комплектующих и полуфабрикатов по спецификации при выпуске единицы прицепа.
12. Добавить мобильный интерфейс смен сотрудников: открыть смену, выбрать участок, закрыть смену с результатом или без результата.

## Ближайшая техническая задача

- Проверить на сервере добавление разной конфигурации к существующему заказу через подбор.

## Ближайшая бизнес-задача

- Подтвердить новую модель производства: участки, склады комплектующих/полуфабрикатов, сотрудники, смены и результаты месяца для директора.

## Что нельзя забыть

- Не смешивать trailers с clinic app и flexity admin.
- Цены по конфигурации могут быть не заполнены и не должны блокировать заказ.
- Источник выбора параметров конфигуратора - матрица допустимости, а не справочник номенклатуры и не ценовые матрицы.
- Разные прицепы в одном заказе должны жить как разные строки заказа, а не как количество одной строки.
